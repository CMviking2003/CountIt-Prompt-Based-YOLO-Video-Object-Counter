# python-yolo-pipeline

Video from https://pixabay.com/videos/people-commerce-shop-busy-mall-6387/ 

To run the demo, execute the following command in the terminal to install required packages:

```
sudo apt-get update && sudo apt-get install -y libgl1
pip install ultralytics opencv-python pandas matplotlib
```

Then run the code

```
python main.py
```

# Exercise

Using the current code as a guide, create you own analysis of the different video.  At the most basic level, you should be counting something other than people.

When ready, submit assignment by executing the following in the terminal:

```
git add -A
git commit -m 'submit'
git push
```
